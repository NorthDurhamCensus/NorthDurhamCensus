# The data

Plain text files. This is where almost every contribution belongs.

| File | Holds |
|---|---|
| `listings.js` | every place in the census (for the map, still to come) |
| `events.js` | hand-verified events |
| `events-imported.js` | **generated nightly** by `tools/fetch-events.mjs`, read live by the North of the Ridges calendar. Do not edit by hand. |
| `events-email.js` | generated by `tools/parse-emails.mjs` from newsletters |
| `stories.js` | reported stories of solidarity |
| `resources.js` | links out, local and further afield |

Each file is a list in square brackets with a one-line header above it. The
header is part of the format other sites read, so do not remove it.

Field-by-field instructions, including the exact spelling of the categories,
are in [../CONTRIBUTING.md](../CONTRIBUTING.md).

**Two rules that prevent almost every mistake:** every item except the last ends
with a comma, and text goes inside "double quotes".
