# The data

Four files. Plain text. This is where almost every contribution belongs.

| File | Holds | Shown in |
|---|---|---|
| `listings.js` | every place in the census | The Census |
| `events.js` | the community calendar | Calendar |
| `stories.js` | reported stories of solidarity | Stories |
| `resources.js` | links out, local and further afield | Resources |

Each file is a list in square brackets with a one-line header above it. The
header exists so the site works when opened straight from disk, with no web
server — do not remove it.

Field-by-field instructions, including the exact spelling of the eight senses,
are in [../CONTRIBUTING.md](../CONTRIBUTING.md).

**Two rules that prevent almost every mistake:** every item except the last ends
with a comma, and text goes inside "double quotes".
